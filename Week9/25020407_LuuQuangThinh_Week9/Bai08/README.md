# Bai 08 - Executable Jar

Build:

```powershell
mvn clean package
```

Run:

```powershell
java -jar target/executable-product-1.0-SNAPSHOT.jar
```

`target` la thu muc Maven tao ra trong qua trinh build, chua class da compile, test reports va file `.jar`.

Pha `package` dong goi output da compile thanh artifact co the phan phoi/chay doc lap.
